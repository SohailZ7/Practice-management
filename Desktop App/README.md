# Desktop App

Desktop companion to the practice's web app (see [SaaS app/](../SaaS%20app/)).

**Status:** the recorder app is in `app/` (see [app/README.md](app/README.md)): local Whisper in-process, Google sign-in, three built-in environments, encrypted transcript queue.

- `docs/session-prompt.md`: the brief for the session that proposes the architecture.
- `specs/`: requirements, versioned as `requirements-vN.md` (latest is current). The first one is written after the architecture is approved.
- The web app's requirements live in `SaaS app/specs/`.
