# Practice Management

This repository holds the practice's software:

- **[SaaS app/](SaaS%20app/)**: the web app (Schedule, Tasks, Employees, Billing, Ledger, Access). Start with its [README](SaaS%20app/README.md); its requirements are in `SaaS app/specs/`.
- **[Desktop app/](Desktop%20app/)**: the desktop companion app. Start with its [README](Desktop%20app/README.md); its requirements will be in `Desktop app/specs/`.

Run all commands for the web app from inside `SaaS app/`.
